# MBR Tools — Privacy-First Online Utilities

Official repository for **[tools.mukulmbr.in](https://tools.mukulmbr.in)**.

This repository is an independent suite of fast, 100% browser-based online tools designed for maximum privacy, zero file server uploads, and high performance.

---

## 🚀 Key Features & Utilities

- **PDF Utilities (`/pdf`)**: Browser-based PDF merger, splitter, converter, and metadata editor.
- **DPI Converter (`/dpi`)**: Resolution calculator converting pixels to physical print dimensions (inches, cm, mm).
- **Image Converter & Resizer (`/image`)**: Convert PNG/JPEG/WebP, compress image quality, and resize dimensions using HTML5 Canvas.
- **JSON Utilities (`/json`)**: Format, validate, beautify, and minify JSON data.

---

## 🛠️ Tech Stack

- **Framework**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Build Tool**: Vite

---

## 💻 Getting Started

### Installation

```bash
npm install
```

### Local Development

```bash
npm run dev
```

Open `http://localhost:5173` to launch the tools dashboard locally.

### Production Build

```bash
npm run build
```

The output bundle will be generated in `dist/`, ready for deployment to `tools.mukulmbr.in`.

---

## 🌐 Custom Domain & Deployment (`tools.mukulmbr.in`)

1. Create GitHub repository `MukulMBR/mukulmbr-tools`.
2. Connect `MukulMBR/mukulmbr-tools` to Cloudflare Pages or Vercel.
3. Configure custom subdomain `tools.mukulmbr.in`.
